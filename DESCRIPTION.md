This mod will make your mining trips more enjoyable by getting rid of the falling gravel problem that everyone has run into before.

When you break a block, any falling gravel above will be instantly broken.

This mod requires [Balm](https://www.curseforge.com/minecraft/mc-mods/balm), which must be installed alongside the mod.

### ![Features](https://mods.twelveiterations.com/img/features-header.png)

*   Instantly breaks falling gravel when breaking the block below
*   Optional on clients. Only those who want to use it need to install it.
